# Portfolio - Apongpoh

A professional portfolio website for a self-taught full-stack developer and cybersecurity professional.

## Sections Included

- Hero / Introduction
- About
- Core Skills
- Experience Timeline
- Featured Projects (template cards you can replace progressively)
- Professional Roadmap
- Contact

## Run Locally

Open `index.html` in your browser.

## Customize

- Update project data in `script.js`.
- Update contact links in `index.html`.
- Adjust visual styles in `styles.css`.
